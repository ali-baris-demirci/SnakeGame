# Snake Game

A simple Snake game implemented in Python using `pygame`. This repository contains the game code (`snake.py`) that you can run locally.

## Requirements

- Python 3.8+
- pygame

Install dependencies:

```bash
pip install -r requirements.txt
```

## Run

```bash
python snake.py
```
